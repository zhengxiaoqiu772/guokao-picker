# 国考选岗器

把 2027 年国考职位表（全国 **19,426** 个职位）缩成「我到底能报哪些」。

填一遍报考条件即时筛选，每个职位都给出**匹配依据**——命中的专业原文高亮显示，结论自己复核，
而不是丢给你一个不透明的「可报 / 不可报」。全程离线，**双击 `index.html` 就能用**，
不装任何东西，也不联网。

---

## 快速开始

1. 双击 `index.html`（Chrome / Edge 都行）。
2. 在左侧「所学专业」填**专业名称**，有专业代码就一起填——这是筛得准不准的关键。
   填完代码后下面会自动推荐专业类目，点一下就加上。
3. 选**毕业年份**。这一项影响很大，见下面「应届身份」。
4. 其余条件按实际情况改，改完即时生效，没有「查询」按钮。
5. 用搜索框、排序和档位筛选进一步收窄。

条件存在本机浏览器里，下次打开还在；「清空条件」一键还原。

## 结果怎么读

每张卡右上角有一枚印章，戳面就是匹配档位：

| 印章 | 档位 | 含义 |
|---|---|---|
| **精准** | 精准命中 | 专业名称或 6 位专业代码直接出现在该职位的专业栏里 |
| **类合** | 专业类命中 | 该职位招的是你勾选的专业类目（如「计算机类」） |
| **门类**（虚线） | 门类命中 · 专业不限 | 只到门类一级或「专业不限」，**建议人工确认** |
| **检索**（靛青） | 按名称检索 | 纯文字查找，**不代表你能报**（见下节） |

卡片上的「专业栏原文」是职位表原文，命中部分标红——档位是判断，原文才是依据。

标题下面竖排**部门代码**和**职位代码**，各带一个「复制」。两个都要看，因为职位代码
**不唯一**：19,426 行里只有 7,178 个不同职位代码，同一个代码会被不同部门复用。

### 按名字找岗位（不填专业也能用）

专业栏空着时可报职位一定是 0（全表只有 7 行不限专业），但「找岗位」和「我能不能报」
是两件事：只要搜索框里有字，工具就切成**纯文字检索**——扫全部 19,426 行，
不套用左侧任何报考条件，印章也换成靛青的「检索」。填上专业后，搜索立刻退回
「在匹配结果里再过滤」。

检索范围：部门名称、用人司局、招考职位、部门代码、职位代码、工作地点、专业栏、备注。
其中代码按位数区分：

- **六位数字**按完整代码找。否则搜 `102000`（外交部）会连带命中职位代码
  `300110200001` 中间那段，多捞出 39 个别的部门
- **十二位职位代码**整段搜，会命中所有复用该代码的部门（`300110001003` 有 82 行）
- **更短的数字**仍按子串找，方便只记得代码前几位

## 应届身份

国考里的「应届」是两层意思，职位表分两种写法，不能当一回事：

| 职位表的写法 | 行数 | 谁可以报 |
|---|---|---|
| 「限2027届高校毕业生」（或只写「2027届高校毕业生」独句成行） | 7,708 | **只限当年毕业**，择业期往届生不行 |
| 「限应届高校毕业生」 | 5,444 | 按报名指南**含择业期**：2025、2026、2027 届未落实工作单位的都算 |
| 完全没提 | 6,274 | 往届也能报 |

所以毕业年份要如实选。选错一档结果会差出上千个岗位：同样条件下 2027 届能报 2,681 个，
2026 届 1,323 个，非应届 540 个。

「限应届高校毕业生」不要求带「限」字（税务系统写作 `应届高校毕业生,男性,…`），
但**必须独立成句**才算限制。下面这些正确地不算：

```
如考生为非应届高校毕业生,要求具有2年以上金融业从业经历   ← 说的是往届
招考对象可为应届高校毕业生                              ← 「可为」是放宽
```

应届身份、性别、英语这三条规则都能在左侧「备注中的要求」里各自关掉，关掉后只提示、
不排除，卡片上会把「你其实不符合」的标签标上 ⚠。

## 其他功能

- **备注风险提示**：自动标出「仅限应届」「限男性」「要求六级」「最低服务期 5 年」等。
  备注原文始终可展开——标签是提示，原文才是依据。
- **附加条件**：户籍/生源、最低服务期、体能/体检、西部/艰苦边远四个开关。这些是岗位自带的
  负担，跟你的资格无关，所以**勾选才排除**，不勾只显示标签。
- **收藏与对比**：底部抽屉里把 2–4 个职位拉成并排对比表，有差异的行高亮。
- **结果分布**：按省份 / 机构层级 / 考试类别 / 招考人数统计，随筛选实时联动。
- **导出与打印**：CSV 为 21 列完整数据（含备注原文、咨询电话、部门网站），Excel 打开不乱码；
  「打印 / 存 PDF」给一份去掉交互外壳的干净清单。

## 匹配规则

### 硬性条件（直接排除）

学历、学位、政治面貌、基层工作最低年限、服务基层项目经历、意向省份、机构层级、考试类别、
职位属性、招录类别、招考人数、面试比例。

- **学历分段生效**：2,033 行写成「本科：XXX；研究生：YYY」。你是本科时，只出现在
  「研究生：」后面的专业不算命中。
- **服务基层项目**按「职位要求 ⊆ 你拥有的」判定，写「无限制」则人人可报。

### 专业匹配（三档）

专业栏是自由文本，常见写法：

```
财政学类、金融学类
080901计算机科学与技术，080910T数据科学与大数据技术
本科：082803风景园林；研究生：0862风景园林
法学类（不含监狱学）
本科生招收计算机类(0809)；研究生招收…
```

处理办法：

- 归一化后按标点切段，提取 6 位代码 / 4 位代码 / 2 位门类码 / 专业名称 / `X类` 类名。
- **排除项**（`不含` / `除外`）命中即剔除或降档；`除 X 外…` 这类反义结构不猜，
  标为需要人工确认。
- **类目词表从职位表本身提取**，不套教育部目录——表里有「财会审计类」「经济金融类」
  这类招录机关自编类目，硬套外部目录必然漏岗。
- **本科阶段的简写视为同一专业**：表里把「会计学」写成「会计」、「审计学」写成「审计」。
  认这一层之前，填「会计」和填「会计学」会看到两拨几乎不相干的结果（只有 3 个重合）；
  现在两者与全称结果一致（565 / 565，「审计」510 / 510）。

### 备注标签

标签从备注文本正则推断，不是官方字段：

- **性别**认「男性」「女性」这两个词，不要求带「限」——税务系统的标准句式是
  `2027届高校毕业生,男性,在本单位最低服务年限为5年`，全表 3,206 行这么写。
  当前认到 4,290 男 / 3,563 女。
- **英语**认「四级 / 六级 / CET-4 / 大学英语4级」等写法，当前 2,895 / 1,998。
  其中 22 行写成阿拉伯数字（外交部、中联部的
  `大学英语4级成绩425分及以上`），早先整批漏标。
  没有放宽到裸的「英语4级」——民航的「国际民航组织英语4级」是飞行人员等级，
  跟四级考试无关（4 行）。另有 18 行是俄语、朝鲜语等**小语种的专业四级**，被一并算作
  要求四级；数量很小，且这些行本来就限小语种专业。
- 英语留空时**不排除**要求英语的职位，而是列出来并标 ⚠，同时告诉你共有多少个
  （实测 281 个，其中 75 个要求六级）。

### 为什么职位数会对不上别的软件

身份键是「部门代码 + 职位代码」。同一个职位代码会被不同部门复用，按职位代码去重
自然会得到不同的数字。

## 文件说明

```
国考选岗器/
├── index.html            页面骨架
├── styles.css            样式（公文 / 印章公报方向）
├── match.js              匹配引擎：纯函数，无 DOM 依赖，浏览器与 Node 共用
├── app.js                界面状态、渲染、收藏对比、统计、导出
├── data/positions.js     构建产物：window.GK_DATA = {…}（4.6 MB）
├── build_data.py         读 .xls → 生成 data/positions.js
├── oracle.py             独立 Python 参考实现，只用来产出对照数字
├── test_match.js         Node 测试：差分测试 + 边界用例
└── 2027年国考职位表（全国）.xls
```

**为什么数据是 JS 而不是 JSON**：页面要能从 `file://` 双击打开，而 `fetch()` 会被 CORS
拦住；`<script src>` 定义全局量可以绕开，代价是不用起服务器。

## 重建数据

换了新的职位表之后：

```bash
pip install xlrd
python -I build_data.py "2027年国考职位表（全国）.xls"
```

脚本会断言总行数，并打印类目词表规模、招录类别分布供核对。

## 测试

```bash
node test_match.js                 # 140 项，全绿才算过
python -I oracle.py "2027年国考职位表（全国）.xls"   # 打印参考数字
```

`oracle.py` 是和 `match.js` 各写一遍的独立实现。两边的档位计数必须一致——测试里的期望值
就是从 oracle 的输出抄的。改了匹配逻辑，两边都要改，然后重跑。

## 已知边界

- **匹配结果仅供参考，以招录机关的最终解释为准。** 专业类目的归属各机关口径不一，
  每张卡都展示专业原文和高亮，就是为了让你自己复核。
- 备注标签是正则推断，可能漏标误标；其中应届 / 性别 / 英语默认参与排除，可关掉。
  「只限当年毕业」这类判断本质是在读中文语义，是全项目最可能出错的部分。
- 数据只包含这份职位表里的信息，没有报名人数、竞争比、进面分数线。
- 条件存在浏览器 localStorage 里，换浏览器或换电脑不会同步。
