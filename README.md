# 选岗器（国考 / 四川省考）

两份职位表，两个页面，顶部互相切换：

| 入口 | 数据 | 默认行为 |
|---|---|---|
| `index.html` · 国考 | 2027 年国考全国 **19,426** 个职位 | 填个人条件，分三档判断能不能报 |
| `sc.html` · 四川省考 | 2027 年四川省考 **4,001** 个职位 / 8,881 人 | **不填任何信息，先浏览、筛选全部职位**；填了「我的条件」再判断资格 |

每个职位都给出**匹配依据**——命中的专业原文高亮显示，结论自己复核，而不是丢给你一个
不透明的「可报 / 不可报」。全程离线，**双击 HTML 就能用**，不装任何东西，也不联网。

---

## 四川省考（`sc.html`）

打开 `sc.html`，或从国考页顶部切过去。数据来自《四川省2027年度公开考试录用公务员
职位情况表》，63 个 sheet 合并为 4,001 个职位、8,881 人。

### 默认就是「浏览全部」

左侧分两组：

- **浏览筛选 · 职位要求**：市州、系统类别、考试类别、考录范围、考录对象、学历要求、
  学位要求、政治面貌要求、招录名额、附加项（体能 / 专业加试 / 民族语言 / 心理测试 /
  民族自治州驻地）、其他要求标签。
- **我的条件（可选）**：学历、学位、政治面貌、性别、应届身份、户籍地、法律职业资格、
  会计 / 审计资格、计算机资格、残疾人证、英语等级、专业名称 / 代码 / 类目。

什么个人条件都不填时，直接列出全部 **4,001 个职位**。浏览筛选只按职位本身的要求收窄，
**不会因为「你不符合」而排除**——户籍能判断的部分填上「户籍地」才开始排除，生源地、
公安院校应届这类工具判断不了的，需要自己看。

只填了学历、学位等硬性条件、还没填专业时，进入「符合硬性条件」一档；填了专业才分
**精准 / 类合 / 门类**三档：

| 状态 | 怎么进入 | 含义 |
|---|---|---|
| 浏览 | 不填任何「我的条件」 | 全部职位，不判断你符不符合 |
| 符合硬性条件 | 填了个人条件，但专业空着 | 学历、学位、政治面貌等已判断，**专业未判断** |
| 可报职位 | 填了专业名称 / 代码 / 类目 | 按专业分三档，卡片上给匹配依据 |

市州有 22 个，用搜索框过滤；专业类目词表从这份表本身提取。

### 专业栏怎么认

- **本科 / 研究生分段**：`本科：法学类 研究生：法学、法律` 只按你的学历所在分段判断。
  学历没填时按本科阶段匹配，页面上会提示。
- **研究生：不限**：研究生阶段不设专业限制，按「门类命中 · 专业不限」处理。
- **类目**：表里大量职位只写「法学类」「计算机类」。只填专业名称会漏掉这些，
  下面会推荐类目，点一下就勾上。推荐来自两处：一是本表里专业名和类目名共享前缀的
  （「计算机科学与技术 / 计算机类」）；二是借国考表的代码前缀（「数据科学与大数据技术
  (080910T) → 0809 → 计算机类」）——省考表几乎不写专业代码，光看它推不出这类关系。
  国考里同一个专业名对不上唯一类目的，一律不推荐，宁缺勿错。
- **代码**：6 位专业代码、4 位一级学科代码、2 位门类代码都认。
- **排除项**：专业栏写「不含 / 除外」的，命中即剔除，并标出需要人工确认。
- **学 / 去学**：表里「会计」与「会计学」按同一专业处理。

### 应届身份与考录对象

职位表的「考录对象」有 5 种写法，工具先结构化，再和你的身份比对：

| 职位写法 | 行数 | 谁可以报 |
|---|---|---|
| 应届高校毕业生 | 1,498 | 仅限应届（2025—2027 届择业期内未落实工作的也算） |
| 应届高校毕业生和符合条件的社会在职、非在职人员 | 2,253 | 应往届都能报 |
| 应届高校毕业生（不含公安院校公安专业应届毕业生） | 80 | 仅限应届，公安院校公安专业应届生除外 |
| 应届高校毕业生（不含公安院校…）和符合条件的社会在职、非在职人员 | 155 | 应往届都能报，公安院校公安专业应届生除外 |
| 两年以上基层工作经历的人员 | 15 | 只有相应基层经历的人能报 |

「我的条件 · 应届身份」只有三档——**应届（含择业期）**、**往届**、**往届（2 年以上基层
经历）**。省考职位只写「应届高校毕业生」，从不写届别，2025、2026、2027 届在规则上完全
等价，所以不像国考那样按毕业年份分档。

- 应届：可报 3,986 个（去掉 15 个要求基层经历的）
- 往届：可报 2,408 个（去掉 1,578 个仅限应届的）
- 往届（2 年以上基层经历）：可报 2,423 个

**「不含公安院校公安专业应届毕业生」这 235 行只打标签、不自动排除**（80 行是仅限应届，
155 行是应届＋社会人员两头都收）。工具没有「你是否公安院校公安专业应届」这一项，推不出来，
卡片上会挂「公安院校应届除外」，需要自己核对。

### 户籍与考录范围

「考录范围」只有三种值，后两种是户籍限制：

| 考录范围 | 行数 | 谁能报 |
|---|---|---|
| 全国 | 3,585 | 不限户籍 |
| 本省 | 322 | 四川省户籍（或生源） |
| 本市州 | 94 | 该市州户籍（或生源），涉及阿坝、甘孜、凉山、达州、雅安、攀枝花 |

「我的条件 · 户籍地」选一个市州，或选「四川省外」：

- **四川省外**：两类全排除，剩 3,585 个
- **成都市**：本省的 322 个照收，只排除 94 个限其他市州的，剩 3,907 个
- **阿坝州**：本州的 31 个照收，剩 3,938 个

户籍地留空 = 不判断，和别的项一样。注意公告写的是「户籍**或生源**」：户籍不在四川、
生源在四川的（尤其应届生），工具按户籍会判你不符合，需要自己核对。生源地这一维没有建模。

### 其他要求

「其他要求」里的性别、法律职业资格、英语等级、会计 / 计算机资格、残疾人专项、矫正视力、
特警技能、户籍、最低服务期等会做成卡片标签，也可以在上方「其他要求」里按标签筛选。

其中三类专项资格在「我的条件」里各有下拉，选「没有」才排除，留空不判断：

| 条件 | 选「没有」时排除 | 判据 |
|---|---|---|
| 会计 / 审计资格 | 44 个 | 「其他要求」写会计（审计）专业技术资格、注册会计师 |
| 计算机资格 | 4 个 | 计算机技术与软件专业技术资格、计算机等级考试证书 |
| 残疾人证 | 15 个 | 写「持有效《中华人民共和国残疾人证》」的残疾人专项职位 |

三类互不重叠，都没有时剩 3,938 个。选「有」不改变结果，只是不再出现在提示条里。

除这三项外，**性别、法律职业资格、英语等级、应届身份、户籍地**也会按你填的个人条件自动排除；
没填的项，以及最低服务期、矫正视力、特警技能等工具无从判断的项，只展示、不排除。
结果上方的提示条会列出这些职位各有多少个，提醒你核对。

## 国考（`index.html`）

### 快速开始

1. 双击 `index.html`（Chrome / Edge 都行）。
2. 在左侧「所学专业」填**专业名称**，有专业代码就一起填——这是筛得准不准的关键。
   填完代码后下面会自动推荐专业类目，点一下就加上。
3. 选**毕业年份**。这一项影响很大，见下面「应届身份」。
4. 其余条件按实际情况改，改完即时生效，没有「查询」按钮。
5. 用搜索框、排序和档位筛选进一步收窄。

条件存在本机浏览器里，下次打开还在；「清空条件」一键还原。

---

### 结果怎么读

每张卡右上角有一枚印章，戳面就是匹配档位：

| 印章 | 档位 | 含义 |
|---|---|---|
| **精准** | 精准命中 | 专业名称或 6 位专业代码直接出现在该职位的专业栏里 |
| **类合** | 专业类命中 | 该职位招的是你勾选的专业类目（如「计算机类」） |
| **门类**（虚线） | 门类命中 · 专业不限 | 只到门类一级或「专业不限」，**建议人工确认** |
| **检索**（靛青） | 按名称检索 | 纯文字查找，**不代表你能报**（见下节） |

卡片上的「专业栏原文」是职位表原文，命中部分标红——档位是判断，原文才是依据。

标题下面竖排**部门代码**和**职位代码**，各带一个「复制」。两个都要看，因为职位代码
**不唯一**：19,426 行里只有 7,178 个不同职位代码，同一个代码会被不同部门复用。

### 按名字找岗位（不填专业也能用）

专业栏空着时可报职位一定是 0（全表只有 7 行不限专业），但「找岗位」和「我能不能报」
是两件事：只要搜索框里有字，工具就切成**纯文字检索**——扫全部 19,426 行，
不套用左侧任何报考条件，印章也换成靛青的「检索」。填上专业后，搜索立刻退回
「在匹配结果里再过滤」。

检索范围：部门名称、用人司局、招考职位、部门代码、职位代码、工作地点、专业栏、备注。
其中代码按位数区分：

- **六位数字**按完整代码找。否则搜 `102000`（外交部）会连带命中职位代码
  `300110200001` 中间那段，多捞出 39 个别的部门
- **十二位职位代码**整段搜，会命中所有复用该代码的部门（`300110001003` 有 82 行）
- **更短的数字**仍按子串找，方便只记得代码前几位

---

### 应届身份

国考里的「应届」是两层意思，职位表分两种写法，不能当一回事：

| 职位表的写法 | 行数 | 谁可以报 |
|---|---|---|
| 「限2027届高校毕业生」（含「限2027年应届高校毕业生」等不带「届」的写法） | 7,739 | **只限当年毕业**，择业期往届生不行 |
| 「限应届高校毕业生」 | 5,413 | 按报名指南**含择业期**：2025、2026、2027 届未落实工作单位的都算 |
| 完全没提 | 6,274 | 往届也能报 |

所以毕业年份要如实选。选错一档结果会差出上千个岗位：同样条件下 2027 届能报 2,681 个，
2026 届 1,323 个，非应届 540 个。

想只看**明确限 2027 届**的职位（把择业期内的 2025、2026 届也排除在外），在「附加条件」
里勾「只看限 2027 届」：上面那 2,681 个会收到 1,358 个。毕业年份选的不是 2027 届时，
这条会和身份冲突，结果必然是 0。

「限应届高校毕业生」不要求带「限」字（税务系统写作 `应届高校毕业生,男性,…`），
但**必须独立成句**才算限制。下面这些正确地不算：

```
如考生为非应届高校毕业生,要求具有2年以上金融业从业经历   ← 说的是往届
招考对象可为应届高校毕业生                              ← 「可为」是放宽
```

应届身份、性别、英语这三条规则都能在左侧「备注中的要求」里各自关掉，关掉后只提示、
不排除，卡片上会把「你其实不符合」的标签标上 ⚠。

---

### 其他功能

- **备注风险提示**：自动标出「仅限应届」「限男性」「要求六级」「最低服务期 5 年」等。
  备注原文始终可展开——标签是提示，原文才是依据。
- **附加条件**：户籍/生源、最低服务期、体能/体检、西部/艰苦边远四个开关。这些是岗位自带的
  负担，跟你的资格无关，所以**勾选才排除**，不勾只显示标签。
  下面还有一个方向相反的开关「只看限 2027 届」：勾上只留备注明确写「2027届高校毕业生」
  的职位，写「限应届高校毕业生」的（按指南含择业期）和根本不限应往届的都排除。
- **收藏与对比**：底部抽屉里把 2–4 个职位拉成并排对比表，有差异的行高亮。
- **结果分布**：按省份 / 机构层级 / 考试类别 / 招考人数统计，随筛选实时联动。
- **导出与打印**：CSV 为 21 列完整数据（含备注原文、咨询电话、部门网站），Excel 打开不乱码；
  「打印 / 存 PDF」给一份去掉交互外壳的干净清单。

### 匹配规则

#### 硬性条件（直接排除）

学历、学位、政治面貌、基层工作最低年限、服务基层项目经历、意向省份、机构层级、考试类别、
职位属性、招录类别、招考人数、面试比例。

- **学历分段生效**：2,033 行写成「本科：XXX；研究生：YYY」。你是本科时，只出现在
  「研究生：」后面的专业不算命中。
- **服务基层项目**按「职位要求 ⊆ 你拥有的」判定，写「无限制」则人人可报。

#### 专业匹配（三档）

专业栏是自由文本，常见写法：

```
财政学类、金融学类
080901计算机科学与技术，080910T数据科学与大数据技术
本科：082803风景园林；研究生：0862风景园林
法学类（不含监狱学）
本科生招收计算机类(0809)；研究生招收…
```

处理办法：

- 归一化后按标点切段，提取 6 位代码 / 4 位代码 / 2 位门类码 / 专业名称 / `X类` 类名。
- **排除项**（`不含` / `除外`）命中即剔除或降档；`除 X 外…` 这类反义结构不猜，
  标为需要人工确认。
- **类目词表从职位表本身提取**，不套教育部目录——表里有「财会审计类」「经济金融类」
  这类招录机关自编类目，硬套外部目录必然漏岗。
- **本科阶段的简写视为同一专业**：表里把「会计学」写成「会计」、「审计学」写成「审计」。
  认这一层之前，填「会计」和填「会计学」会看到两拨几乎不相干的结果（只有 3 个重合）；
  现在两者与全称结果一致（565 / 565，「审计」510 / 510）。

#### 备注标签

标签从备注文本正则推断，不是官方字段：

- **性别**认「男性」「女性」这两个词，不要求带「限」——税务系统的标准句式是
  `2027届高校毕业生,男性,在本单位最低服务年限为5年`，全表 3,206 行这么写。
  当前认到 4,290 男 / 3,563 女。
- **英语**认「四级 / 六级 / CET-4 / 大学英语4级」等写法，当前 2,895 / 1,998。
  其中 22 行写成阿拉伯数字（外交部、中联部的
  `大学英语4级成绩425分及以上`），早先整批漏标。
  没有放宽到裸的「英语4级」——民航的「国际民航组织英语4级」是飞行人员等级，
  跟四级考试无关（4 行）。另有 18 行是俄语、朝鲜语等**小语种的专业四级**，被一并算作
  要求四级；数量很小，且这些行本来就限小语种专业。
- 英语留空时**不排除**要求英语的职位，而是列出来并标 ⚠，同时告诉你共有多少个
  （实测 281 个，其中 75 个要求六级）。

#### 为什么职位数会对不上别的软件

身份键是「部门代码 + 职位代码」。同一个职位代码会被不同部门复用，按职位代码去重
自然会得到不同的数字。

## 文件说明

```
国考选岗器/
├── index.html              国考页面骨架
├── sc.html                 四川省考页面骨架
├── styles.css              共用样式（公文 / 印章公报方向）
├── sc.css                  省考页面的少量补充
├── match.js                国考匹配引擎；省考只复用它归一化与专业分词
├── sc_match.js             四川省考匹配引擎：纯函数，浏览器与 Node 共用
├── app.js                  国考界面：状态、渲染、收藏对比、统计、导出
├── sc_app.js               省考界面：同上，默认浏览模式
├── data/positions.js       国考构建产物：window.GK_DATA = {…}（4.6 MB）
├── data/sc_positions.js    省考构建产物：window.SC_DATA = {…}（1.4 MB）
├── build_data.py           读国考 .xls → data/positions.js
├── build_sc_data.py        读省考 .xlsx（63 个 sheet）→ data/sc_positions.js
├── oracle.py               国考独立 Python 参考实现，只用来产出对照数字
├── test_match.js           国考 Node 测试
├── test_sc_match.js        省考 Node 测试
├── 2027年国考职位表（全国）.xls
└── 四川省2027年度公开考试录用公务员职位情况表).xlsx
```

**为什么数据是 JS 而不是 JSON**：页面要能从 `file://` 双击打开，而 `fetch()` 会被 CORS
拦住；`<script src>` 定义全局量可以绕开，代价是不用起服务器。

## 重建数据

换了新的职位表之后：

```bash
pip install xlrd openpyxl
python -I build_data.py "2027年国考职位表（全国）.xls"
python -I build_sc_data.py "四川省2027年度公开考试录用公务员职位情况表).xlsx"
```

两个脚本都会打印总职位数供核对；省考脚本按「职位编码」定位每个 sheet 的表头，
所以 63 个 sheet 表头行数不一致、列集合有 3 种，都不用改代码。

省考脚本还会读 `data/positions.js`，从国考的「专业代码 → 专业类」表里补一份类目推荐
（省考表本身不写代码，推不出来）。这个文件不存在时自动跳过，构建照常完成，只是推荐会少一些。

## 测试

```bash
node test_match.js                 # 国考 152 项，全绿才算过
node test_sc_match.js              # 省考 110 项
python -I oracle.py "2027年国考职位表（全国）.xls"   # 打印国考参考数字
```

`oracle.py` 是和 `match.js` 各写一遍的独立实现。两边的档位计数必须一致——测试里的期望值

省考的期望值直接来自这份表的真实计数；换源表重跑 `build_sc_data.py` 后，按新数字更新
`test_sc_match.js`。

## 已知边界

- **匹配结果仅供参考，以招录机关的最终解释为准。** 专业类目的归属各机关口径不一，
  每张卡都展示专业原文和高亮，就是为了让你自己复核。
- 备注标签是正则推断，可能漏标误标；其中应届 / 性别 / 英语默认参与排除，可关掉。
  「只限当年毕业」这类判断本质是在读中文语义，是全项目最可能出错的部分。
- 数据只包含这份职位表里的信息，没有报名人数、竞争比、进面分数线。
- 条件存在浏览器 localStorage 里，换浏览器或换电脑不会同步。

省考特有的几条：

- **户籍按「户籍地」判断，生源不判断**。「考录范围」写「本省」「本市州」的职位按户籍
  排除；但公告口径是「户籍或生源」，生源满足而户籍不满足的，工具会判错。户籍地留空时
  只提示、不排除。
- **公安院校公安专业应届除外只打标签**。那 235 行标 `policeSchool`，工具区分不了你
  是不是公安院校公安专业应届。
- **个别「其他要求」无法判断**：3 年以上司法辅助工作经历、持一级建造师证、
  「主修专业为…」这类条款会原样展示但不下结论。
- 省考标签同样是正则推断，与国考一致：标签是提示，卡片上的原文才是依据。
